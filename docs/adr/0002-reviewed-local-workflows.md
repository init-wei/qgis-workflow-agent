# 受审核的本地有限工作流

首期采用本地单用户、单后台进程与专用 QGIS profile，每次至多执行一项 GIS 任务。保留浏览器、FastAPI、LangGraph、MCP 与独立 QGIS，收敛成唯一类型化 TaskPlan；优先解决真实空间任务、审核和恢复，而不引入队列、多用户框架或任意代码执行。

原始资产不可覆盖；外部写入超时或重启后结果不明时需要核查，不承诺 exactly-once。Checkpoint 保证的恢复范围是已声明的审核暂停点。六类经审阅方案模板是唯一可执行模板来源，先使用标签、别名和输入条件匹配；完整文档 RAG 或向量服务须由失败证据和新规格证明必要性后再加入。
