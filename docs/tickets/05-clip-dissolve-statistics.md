# T05：裁剪、融合、统计与第二条组合

**正式 issue：** [#25](https://github.com/init-wei/qgis-workflow-agent/issues/25)；状态以 GitHub 为准。

**What to build：** 用户提交有限的裁剪/融合/统计请求，经审核得到可读取空间产物与有单位的统计结果，补齐六类首期能力。

**Blocked by：** T03。

**输入：** 规格 AC06、AC07、AC10；三个算法族的小型独立预期。

**验收：**

- [ ] 裁剪、全部/按字段融合、计数/数值字段/投影面积统计在真实 QGIS 环境可用。
- [ ] 至少一条裁剪→融合或统计的组合确实消费上一步结果；字段、CRS 与单位条件在审核前明确。
- [ ] 合法空结果与运行失败区分；空结果统计含义准确，不用“没有文件”代替成功空结果。
- [ ] 独立预期检查交集、分组数量、属性/面积关系及数值汇总；异常不能发布成功成果。
- [ ] 页面可查看空间结果和统计，并通过统一业务查询读取结果，不增加专用状态或重复执行链。

**证据：** 三类任务及组合的实际文件/统计、输入来源、独立判断和适用回归。复用已有 Adapter/验证 Seam，不为每类任务新建一套 Agent。
