# T02：审核、修订与恢复不串任务

**正式 issue：** [#22](https://github.com/init-wei/qgis-workflow-agent/issues/22)；状态以 GitHub 为准。

**What to build：** 用户可以反复修改计划，处理风险审核，并在刷新、会话切换或后台重启后继续正确任务；重复点击不会重复执行。

**Blocked by：** T01。

**输入：** 规格 AC04、AC05、AC08、AC09、AC10 和三类审核等待点。

**验收：**

- [ ] 多次拒绝及达到规划自动尝试上限都不自动批准；修订后旧批准返回冲突。
- [ ] 受控新工程保存进入风险审核；批准、拒绝、过期和重复决策都与当前调用匹配，实际调用次数正确。
- [ ] 三个等待点可刷新、重选会话及重启恢复；继续后不重复已经完成的操作。
- [ ] 切会话关闭旧弹窗并加载新快照；旧流结束不清理新请求，已在执行时重复 resume 不启动第二次执行。
- [ ] 单执行限制覆盖不同会话；忙时给出可理解提示，不新增排队机制。
- [ ] 模拟写操作结果未知时保持需要核查，不自动重放；页面停止读取不会被宣告为 QGIS 已取消。

**证据：** 公开应用 Interface 的状态/调用计数与浏览器专项，至少一组真实 PostgreSQL 暂停重启和真实受控工程保存。只读 fake 的测试不能替代这些集成证据。
