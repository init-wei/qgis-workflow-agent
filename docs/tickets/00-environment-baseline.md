# T00：建立隔离开发基线

**正式 issue：** [#20](https://github.com/init-wei/qgis-workflow-agent/issues/20)；状态以 GitHub 为准。

**What to build：** 开发者获得一个可重建且不影响其他项目的目标环境，并知道原型原本通过和失败的项目。此切片是环境前置门槛。

**Blocked by：** None。

**输入：** 最终规格、原仓库固定提交及现有环境探测。进入实施时才克隆到用户要求的 projects 目录，核对远端变化、目标仓库指引和许可证/第三方来源。

**验收：**

- [ ] 使用目标独立 checkout 与分支；uv Python、Node、锁文件及实际 QGIS/GDAL/PROJ 版本记录完整。
- [ ] 项目专用 PostgreSQL 数据库/容器、空闲端口与专用 QGIS profile 就绪；未覆盖当前数据库、用户 profile 或私密配置。
- [ ] 运行原始适用测试、Python 导入/编译和前端构建；原有失败、跳过、外部条件与命令真实记录。
- [ ] 示例输入可由跟踪的合成数据获得，不依赖旧 shared 运行目录。
- [ ] 所有凭据、运行数据与产物处于忽略范围；没有把其他项目的 key 当作默认配置。

**证据：** 环境记录与命令结果、git 差异、合成输入来源，覆盖 AC01。真实模型与桌面闭环在后续切片验证；本切片不伪称业务已可用。
