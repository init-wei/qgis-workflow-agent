# T03：真实重投影、缓冲与空间验证

**正式 issue：** [#23](https://github.com/init-wei/qgis-workflow-agent/issues/23)；状态以 GitHub 为准。

**What to build：** 用户审核一项重投影→缓冲→查看任务，得到空间验证通过的真实文件，而不只是工具完成文字。

**Blocked by：** T01。

**输入：** 规格 AC06、AC07、AC10；固定合成输入与独立坐标/距离预期。

**验收：**

- [ ] 能力与输入元数据进入计划；不支持算法、无可靠 CRS、米/度歧义和缺参数明确要求修正。
- [ ] 真实 QGIS 执行两类算法，缓冲实际使用前一步重投影产物；原始文件不覆盖。
- [ ] 读回检查目标 CRS、数量/属性、几何、坐标/距离等预定容差；错误产物不能标为成功交付。
- [ ] 页面分别呈现工具执行、空间验证、用户确认；业务记录可解释失败并关联输入和输出。
- [ ] 至少一个“调用正常但结果不符合预期”反例被验证器拒绝；错误理由不是模型凭截图判断。

**证据：** 输入、真实空间产物、独立预期、容差、验证报告、QGIS/provider 版本和用户路径。此切片通过才允许进入云端观测接入。
