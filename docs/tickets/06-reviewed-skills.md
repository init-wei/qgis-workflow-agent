# T06：用已验证 Skill 生成待审核方案

**正式 issue：** [#26](https://github.com/init-wei/qgis-workflow-agent/issues/26)；状态以 GitHub 为准。

**What to build：** 用户用新文件、新距离或新字段复用一条已审阅方案，仍能检查并批准实际调用。

**Blocked by：** T05。

**输入：** 规格 AC12；六类任务的真实成功结果和既有 Skill 模型。

**验收：**

- [ ] 六类基础模板有版本、人工审阅及真实验证来源；Skill 是唯一可执行模板定义。
- [ ] 通过标签/别名与输入条件选择候选；候选影响草稿，不能直接授权执行。
- [ ] 新文件/参数可替换；数值和布尔类型保留，未解析占位符及缺参数被拒绝。
- [ ] 命中与未命中均走同一计划验证、审核与受控执行 Interface。
- [ ] Cookbook 不再作为第二套可执行方案源；没有自动学习、自动注册发布或额外向量服务。

**证据：** 真实新数据/参数任务、模板审阅与来源、非法占位符反例、未批准零调用。模板开发样例与后续留出集分离。
