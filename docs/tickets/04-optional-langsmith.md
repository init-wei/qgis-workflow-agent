# T04：可关闭的 LangSmith Cloud 观测

**状态：** 本地草稿；选型已确认，接入未实现、未发布。

**What to build：** 开发者从 LangSmith 查看真实成功和失败的图/模型/工具/验证过程，应用在关闭观测时仍完整可用。

**Blocked by：** T03。外部条件：用户项目的 LangSmith Cloud 账号、目标和凭据可用。

**输入：** 规格 AC11、AC13；已有 LangGraph/LangChain 依赖及实际业务 task ID。

**验收：**

- [ ] 使用官方集成与少量自定义 span；不托管 Agent 执行，不引入 Langfuse 或多平台抽象层。
- [ ] 默认关闭、缺 key 或主动停用时，真实闭环、PostgreSQL 恢复与产物查询正常。
- [ ] 开启后能从平台关联一次真实成功和一次失败/结果未知至本地业务记录，审核前后多份 trace 可按业务 ID 关联。
- [ ] 模型 usage 与费用来源核实；缺失为未知；程序退出前提交行为与对业务耗时的影响有实际检查。
- [ ] 平台评分和运行无异常不成为业务成功或批准依据；大型空间文件和凭据不写入遥测。

**证据：** 实际平台 run/trace、对应 task ID、开关对照及记录。仅 fake SDK 测试不满足云端接入验收；没有凭据时明确未验收，不阻塞其他 GIS 切片开发。
