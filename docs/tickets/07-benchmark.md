# T07：可复现的基线与模板评测

**正式 issue：** [#27](https://github.com/init-wei/qgis-workflow-agent/issues/27)；状态以 GitHub 为准。

**What to build：** 维护者能在同一批任务上比较版本，并解释失败、人工改动、耗时和模型成本；结果可用于回归与简历。

**Blocked by：** T02、T06。平台实验视图另需 T04 通过；本地固定数据实验不依赖平台凭据。

**输入：** 规格 AC14、[评测约定](../implementation-plan.md#评测执行约定)、各任务空间评价器。

**验收：**

- [ ] 开发集与 24 个留出请求区分；至少八类异常及浏览器专项有固定输入和预期。
- [ ] A0/A1 使用固定配置配对运行，报告实际重复数；预置 repair_arguments 不冒充检索修复。
- [ ] 汇总计划有效率、首次/最终完成率、人工改动、恢复/审核、假成功、匹配、延迟、token/费用；分母和缺失值明确。
- [ ] 失败、合法空结果、外部中断与重跑保留；没有静默剔除或未实测的提升数字。
- [ ] 本地原始结果可重现；T04 通过时平台实验链接能关联具体业务任务，未通过时明确未验收；不自建通用实验 Dashboard。
- [ ] 固定反例的假成功为零，未批准执行为零；效果指标给 n/N，不把小样本夸成泛化或显著提升。

**证据：** 逐次 JSONL/CSV、版本与配置、实际产物/验证、平台实验（可选独立验收）、失败分析和浏览器结果。没有真实运行的条目保持未验收。
