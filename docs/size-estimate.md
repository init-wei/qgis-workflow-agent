# 代码规模：原始估算与 V1 实测

原始规划日期：2026-10-30；V1 重测：2026-10-31。原始估算保留用于比较，最终数字按同一范围读取固定 Git 对象；代码规模不是质量或个人产出的证明。

## 统计口径

- 基线固定为 [`init-wei/qgis-workflow-agent@9602db0dd517ab6f0ce0ea4514174425b9a55142`](https://github.com/init-wei/qgis-workflow-agent/tree/9602db0dd517ab6f0ce0ea4514174425b9a55142)。这是规划阶段的固定基线，不随分支更新。
- 通过 GitHub 只读取得文件树及 105 个 `.py`、`.vue`、`.ts`、`.js`、`.css` 文本文件；逐文件返回的 blob SHA 与固定树核对一致，所有文件计数成功，无缺失文件。
- 物理行：统一 CRLF 后按换行分行，最后一个行结束符不额外计空行。非空行：其中去除首尾空白后非空的行数。
- **非空行包含注释、Python docstring、Vue 模板和 CSS，不等于逻辑代码行/SLOC。** 目标估算采用同一口径，不把代码压成一行降低统计。
- 不计第三方依赖、锁文件、生成物、JSON fixture/Skill 数据、SQL/HTML/YAML 配置、文档、图片、ZIP、运行数据与虚拟环境。若后续采用不同工具，必须先统一范围再比较。
- [逐文件 CSV](source-lines.csv)保存路径、blob SHA、分类和两种行数，便于在目标 clone 后复算。该计数来自规划阶段，早于本轮目标 checkout 与环境验证。

## 原始预测所考虑的范围

可收敛项：两套 SSE、旧 Plan/TaskPlan 互转、协议猜测、未消费检索上下文、自动评分归档、默认静态 demo/GeoTool 导出链、完整 TraceDemo 开发者界面，以及重复 API/消息处理。保留有用能力不等于保留所有历史实现。

新增或需要补实项：附件到执行的完整路径、步骤引用与参数契约、三类审核恢复、必要业务持久化、六类任务的真实空间校验、可选 LangSmith 接线和固定留出集运行器。

第三方追踪与实验 UI 由 LangSmith 提供；QGIS 算法由发行版提供；checkpoint 由官方 PostgreSQL saver 提供。它们不计入自有代码，也不重复实现。

本范围没有包括完整文档 RAG。若后续证据支持增加语料摄取、版本化检索和检索评价，将单独估算，不把它挤进本区间而保留隐形工作。

## 使用估算的方式

本区间用于发现范围膨胀，不是验收上限。实现后若超出，先解释是否存在新的真实用户路径、保留的兼容链或可复用平台能力；不通过删除错误处理、空间校验和必要测试满足行数目标。过度压缩函数和类型同样不符合可读性要求。

## 为什么超过估算

按原目录口径的生产代码 13,687 非空行，比原规划上限 7,000 多 6,687；全部 38,585，比 12,000 多 26,585。原预测低估了以下职责，不能继续作为已达成的“精简效果”宣传：

- **真实空间验证与输入完整性。** 六类有限任务仍需 CRS、单位、几何、属性、空结果、数值及前序文件身份检查；三个隔离系统 Python 检查器实际进入生产路径。它们补足原型不能仅凭工具回显判断的事实。
- **审核、持久化与恢复。** 同一任务的修订、具体风险调用、结果确认、互斥、已完成前缀、外部写入未知及人工核查，需要必要业务事实和恢复一致性。Checkpoint 和 LangSmith 不能替代这些边界。
- **测试与固定评测。** 测试达到 17,638 非空行；评测运行器、fixture、独立数学预期、用量完整性和 unknown 分母也占 scripts。原先全部 scripts 500–800 行的预测明显不足。行数不等于测试通过数或覆盖完备性。
- **保留的历史与兼容边界。** 默认静态 Trace Demo、三个 API 及闲置自动评分计算已删除；离线历史 CLI、必要业务 ExecutionTrace 和未核实旧数据库数据仍明确保留，没有为追求数字而 DROP 数据或删除诊断路径。

T08 的 `3b8f296` 清理检查点在九个既有源码文件中净减少 417 物理行、352 非空行，新增可复现统计脚本为 150 物理行、137 非空行；该阶段全部所计源码为 38,286。随后真实验收发现完成会话无法恢复结果卡、模型摘要引用旧修订，形成 [#30](https://github.com/init-wei/qgis-workflow-agent/issues/30)。补修收敛自由模型总结、恢复业务事实并增加永久浏览器回归后，最终为 38,585；相对修复后 `054baa4` 的 38,501 净增加 84 非空行（最终包含新浏览器 CJS）。这些是阶段实际差异，不能解释为实现了原先整体压缩目标。后续简化仍以消费者、受保护行为和验证证据为依据。实际验收、评测局限与可用于简历的表述见[验收证据入口](onboarding/acceptance.md)。
