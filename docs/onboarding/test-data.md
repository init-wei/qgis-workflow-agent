# 用户提供的 GIS 测试数据

日期：2026-10-30。原始 ZIP 保留在 RS Harness 研究归档，完整解压内容位于本项目 `data/test-data/raw/`。精确文件、SHA-256、图层和实测元数据由 [manifest.json](../../data/test-data/manifest.json)拥有；本页说明用途和验证边界。

总计 196 个文件、178,470,702 bytes（约 170.2 MiB），包含 31 个矢量图层和 8 幅栅格。所有实测图层 CRS 均识别为 EPSG:4326。Shapefile 的 shp/shx/dbf/prj、可用 cpg、XML、lyr 与说明文件全部保留；lyr 仅保留，没有验证其在 QGIS 中的样式兼容性。

WSF 包名虽含 116_36，实际包含 `112_22`、`114_32`、`114_34`、`116_34`、`116_36`、`116_38`、`118_32`、`120_30` 八幅影像。像元值语义不由文件名推断，后续设计统计规则前须读取权威产品说明。

ShakeMap 包名虽为 ci10542525，实际保留 `ci10148002`、`ci10169094`、`ci10184394`、`ci10537093`、`ci10542525` 五个目录；每组含 mi、pga、pgv、psa03、psa10、psa30 六个面图层。随包 XML 标注 USGS 来源；其中模板日期和零边界等字段不当作事件实际日期或实际空间范围。空间信息以文件读取结果为准。

## 原始数据与派生数据

- `raw/` 作为输入保留，所有派生结果写 `derived/` 或后续任务独立输出目录，不覆盖原始文件。两个目录已加入 Git 忽略；CI 不下载或依赖它们。
- 原 ZIP 在用户提供位置保留；本轮没有重复复制 ZIP、修改内容、重投影、拼接或裁剪。再次导入同名目录前先比较完整文件清单和 SHA-256，内容不同则停止，不覆盖。
- 当前 V1 输入契约为小型 2D GeoJSON/GeoPackage。后续可从这两组矢量导出适当区域、字段和要素的小型 GeoPackage，记录原始 checksum、筛选条件、CRS、输出 checksum 与独立预期。
- WSF 栅格保留为后续集成/范围扩展素材，不因此增加 V1 栅格分析能力或 SAM3 依赖。
- 默认单测仍使用跟踪的微型合成 fixture；这些实测数据没有自动成为 T07 留出集，也不含已标注真值。开发/留出拆分和异常场景继续按[评测口径](../implementation-plan.md)设计。

Natural Earth 的全球数据、ShakeMap 的事件数据及 WSF 影像不保证任意组合在空间上相交。后续组合任务先核对范围与 CRS；不相交可用于合法空结果反例，不能把未经检查的数据组合当作正常裁剪样例。EPSG:4326 的角度单位不能直接当作米进行缓冲或面积计算。

## 本轮验证

使用 Python 标准库完整解压并完成 ZIP 成员 CRC 读取校验，记录 ZIP 和 196 个文件的 SHA-256。用发行版 GDAL/OGR 3.12.2 只读打开全部 39 个空间图层，读取 CRS、范围、字段、数量/尺寸；每个非空矢量图层读取首个几何，每个栅格波段解码三个单像元样本。GDAL_PAM_ENABLED=NO，未写入 aux.xml 或其他附属数据。

上述验证证明解压内容完整及基础可读取性。尚未完成全部几何有效性、全像元扫描、数值/类别语义、真实业务工作流和解译质量验收；不以只读打开代替空间正确性。

本轮来源是用户提供的 ZIP 与随包元数据；没有重新下载或判断可公开再分发许可。发布真实数据或衍生数据时再核对相应来源与要求。
