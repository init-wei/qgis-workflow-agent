# Triage 标签

| 规范角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 外部需求待评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分；仍须检查 blockers |
| ready-for-human | ready-for-human | 必须人工处理 |
| wontfix | wontfix | 明确不实施 |

由本次已确认规格生成的 tickets 不再 triage。ready-for-agent 不代表依赖已满足。`qwa-v1` 用于本次重构的任务集合。
